cqlprof

Cassandra has no EXPLAIN, but it has tracing. cqlprof reads the trace and says where the time and the work went.

GitHubcrates.io
$ cargo install cqlprof

5,000 deleted rows in one partition

SELECT * FROM pf.q WHERE pk = 1

  trace (scylla)   server 833 µs, 1 replica targeted

  warning [PROF001] scanned 2990 tombstones to return 10 live rows
