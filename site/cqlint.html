cqlint

Format CQL and catch the statements that hurt at scale, in milliseconds. Built on the lexer of cqlc.

GitHubcrates.io
$ cargo install cqlint
Format

One layout, safe by construction

Before

any style

select id,name from ks.users where id = ? and name > 'a' order by name desc limit 10;

After

keywords, clauses, wrapping, comments kept

SELECT id, name
FROM ks.users
WHERE id = ?
  AND name > 'a'
ORDER BY name DESC
LIMIT 10;

Safety net

tokens and comments must be unchanged

Checked on real KillrVideo and cqlc files; if the token stream would change, the file is left alone.
