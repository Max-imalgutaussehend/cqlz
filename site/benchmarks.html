Reproduce

Run it yourself

git clone https://github.com/Max-imalgutaussehend/cqlz && cd cqlz/benchmarks
cargo bench --bench frontend        # cqlc vs sqlparser
cargo bench --bench inference       # cql-ai vs cqlc
cargo run --release --bin realworld # KillrVideo coverage
cargo run --release --bin ycsb -- 50000 10   # cqlx vs raw driver (Docker)

git clone https://github.com/Max-imalgutaussehend/cqlz-lab && cd cqlz-lab
cargo run --release -p cqlz-gym -- eval --policy artifacts --instances 8 --exact-seconds 15
cargo run --release -p cqlz-gym -- bench
Data sources and what is not measured

KillrVideo schemas and queries (Apache-2.0), YCSB core workloads A/B/C, NoSQLBench (cql-keyvalue2, cql-tabular2, cql-iot, cql-timeseries2), cassandra-stress profiles, TSBS CPU table, DataStax data-modelling examples (shapes of the gym workloads). Not measured: cluster throughput, multi-node scaling, tail latency under overload, one machine only.
