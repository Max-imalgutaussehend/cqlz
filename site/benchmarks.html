Reading: the three are statistically indistinguishable. Run-to-run spread (up to 30 % between runs) is larger than any gap between contenders, so no ranking can be claimed. cqlx is not measurably slower than the raw driver, which is the point of "zero overhead". Deviations from canonical YCSB: an update rewrites the whole row (cqlx has no partial update yet, so all contenders do the same), keys are not hash-scrambled, and this is one node, not a cluster.

cql-ai

Cost, accuracy and honesty

Time to check the same 36 statements (log scale not used: the gap is the point)
cqlc analysis
0.10 ms

The honest comparison: the neural model is about 400× slower than cqlc's own analyzer on statements both can handle. cql-ai check still takes only about 52 ms wall clock end to end (process start and weights included), far inside a CI budget. Its niche is tolerating partial queries and reporting probabilities; use cqlc check when you have a complete schema.
EvaluationExact label-set matchStatements
synthetic, unseen schemas94.9 %10,000
real KillrVideo queries that cqlc can analyse60 % (9 / 15)15

On the real queries the model's per-label results were MissingPartitionKey tp 2 / fp 2 / fn 1, NonKeyRestriction tp 2 / fp 1 / fn 2, OrderByMismatch tp 1 / fn 1. Fifteen statements are too few for a confident number, but the drop from 95 % to 60 % is the honest signal: the model was trained on synthetic queries and real CQL (functions, collection filters, dates) is out of distribution. A real labelled corpus is the next step.

Reproduce

Run it yourself

# cqlc front end, cql-ai latency, token statistics, real-world KillrVideo check
git clone https://github.com/Max-imalgutaussehend/cqlz && cd cqlz/benchmarks
cargo bench --bench frontend
cargo bench --bench inference
cargo run --release --bin token_stats
cargo run --release --bin realworld -- <cql-ai model dir>

# cqlx vs raw driver vs charybdis (needs Docker)
cargo run --release --bin ycsb -- 50000 10

# cqlz-gym
git clone https://github.com/Max-imalgutaussehend/cqlz-lab && cd cqlz-lab
cargo run --release -p cqlz-gym -- eval --policy artifacts --instances 8 --exact-seconds 15

Not measured: cluster-scale throughput, tail latencies under overload, multi-node scaling, comparison with Cassandra rather than ScyllaDB.
