The family

Same goal, three entry points. All three build on the ScyllaDB Rust driver and speak plain CQL.

Schema-first

cqlc

Write .cql schema and named queries. cqlc type-checks them offline and generates typed async Rust, like sqlc for Cassandra.

Read more →
Code-first

cqlx

Write a Rust struct. #[derive(CqlEntity)] generates the table, inserts and a type-state query builder that cannot forget a partition key.

Read more →
Analysis

cql-ai

A 0.6M-parameter Transformer over cqlc lexer tokens that flags anti-patterns in CI with probabilities, in milliseconds.

Read more →

cqlc-core is the shared foundation: cqlx's CLI parses existing schemas with it and verifies generated DDL against it, and cql-ai uses its lexer as the tokenizer and its analyzer as the source of training labels.
